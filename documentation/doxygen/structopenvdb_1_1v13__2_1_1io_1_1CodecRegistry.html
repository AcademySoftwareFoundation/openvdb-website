Detailed Description

A thread-safe, process-global registry that maps codec names to Codec instances.

Codecs are identified by a unique string name (typically provided by Codec::name()) and stored as Codec::Ptr (i.e. std::unique_ptr<Codec>).

Typical usage
// Register a custom codec once at start-up (e.g. from initialize()):
CodecRegistry::registerCodec<MyCodec>();

Note
Attempting to register a codec whose name is already present throws openvdb::KeyError. Call isRegistered() first when the caller cannot guarantee uniqueness.
