Detailed Description

template<typename T, int ROWS, int COLS>
class nanovdb::math::MatBase< T, ROWS, COLS >

Base class for fixed-size matrices. Provides shared element-wise arithmetic, scalar arithmetic, equality, transpose, mat*mat, and mat*vec. Storage is a flat row-major array mData[ROWS * COLS]. Derived classes supply constructors plus any dimension-specific extras (e.g. inverse() on Mat2).
