Detailed Description

template<typename T>
class nanovdb::math::Mat2x3< T >

2x3 row-major matrix.

Intentionally NOT alignas-elevated: its byte size (6*sizeof(T)) is not a power-of-2 multiple of alignof(T), so any alignas(N > alignof(T)) would force tail padding and break packed-array layout plus on-disk format compatibility.
