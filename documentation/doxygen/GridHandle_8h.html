void validateGridLayout (const std::vector< GridHandleMetaData > &meta, uint64_t bytes)
 Checks that meta describes grids laid out back to back from offset zero inside bytes of storage, each starting at a multiple of NANOVDB_DATA_ALIGNMENT and naming a grid type below GridType::End. This is all the validation a handle adopting caller-supplied metadata performs: no header is read. No grids at all is accepted only over an empty buffer (an empty handle).
void parseHostGridChain (const GridData *head, uint64_t bytes, std::vector< GridHandleMetaData > &meta)
 Validates the grid chain in bytes of host-readable memory headed by head and fills meta with one entry per grid: every header must be valid, carry its expected index and the chain's total count, and fit inside the buffer, so a truncated buffer or a forged header is rejected before its metadata is trusted. This is the host counterpart of the device-side chain parse. Like it, this does not require grid offsets to be aligned, unlike GridHandle::adopt.
