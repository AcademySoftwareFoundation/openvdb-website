Detailed Description

Receives formatted log messages. Subclass this to route OpenVDB diagnostics into a host application.

Sinks are called on the thread that logged the message, so an implementation must be thread safe. A sink must not throw.

Example
class MySink: public openvdb::logging::Sink
{
public:
MySink(): Sink("mysink") {}
void append(openvdb::logging::Level level, const std::string& message,
const char* file, int line) override
{
// forward to the host application's own logging system
}
};
openvdb::logging::addSink(std::make_shared<MySink>());
