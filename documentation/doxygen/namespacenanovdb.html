Detailed Description

Defines a simple memory pool used to call cub functions that use dynamic temporary storage.

See nanovdb/tools/cuda/PointToGrid.cuh and nanovdb/tools/cuda/DistributedPointToGrid.cuh for examples. Also note that this explains the somewhat unusual API with direct access to private member data.
