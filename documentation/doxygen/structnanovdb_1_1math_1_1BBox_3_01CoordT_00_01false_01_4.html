Detailed Description

template<typename CoordT>
struct nanovdb::math::BBox< CoordT, false >

Partial template specialization for integer coordinate types.

Note
Both min and max are INCLUDED in the bbox so dim = max - min + 1. So, if min = max the bounding box contains exactly one point and dim = 1!

Splitting constructor (used by parallel range-based iteration).

Halves the box along its longest axis: other keeps the upper half, the newly constructed BBox is the lower half. The SplitT tag type is ignored; it exists so this overload doesn't collide with the copy constructor.
