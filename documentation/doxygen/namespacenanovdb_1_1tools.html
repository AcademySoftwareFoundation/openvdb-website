 CPU counterpart of tools::cuda::VoxelBlockManager. Provides host-side decode of the inverse maps (sequential index -> leaf + voxel offset) for a single voxel block. Allocate buffers and build a VoxelBlockManager on the host from a ValueOnIndex grid. Uses nanovdb::util::forEach to process lower internal nodes in parallel.

Template Parameters
Log2BlockWidthLog2 of the number of active voxels per VBM block
BufferTBuffer type for the returned handle (default: HostBuffer)
Parameters
gridHost-accessible ValueOnIndex grid (must satisfy isSequential())
firstOffsetFirst active-voxel offset covered by this VBM; must satisfy firstOffset == 1 (mod BlockWidth). Pass 0 (default) to use 1, which covers the full grid from the first active voxel.
lastOffsetLast active-voxel offset covered by this VBM. Pass 0 (default) to use grid->activeVoxelCount(), covering the full grid.
nBlocksAllocated capacity in blocks; must be >= ceil((lastOffset - firstOffset + 1) / BlockWidth). Pass 0 (default) to use the minimum required capacity.
poolOptional pool buffer for allocation (passed to BufferT::create)
Returns
A fully constructed VoxelBlockManagerHandle
