Detailed Description

template<typename Vec3T>
struct nanovdb::math::BaseBBox< Vec3T >

Common base for floating-point and integer bounding boxes; not constructible directly (only as a base of BBox).

Stores the closed-segment endpoints mCoord[0] (min corner) and mCoord[1] (max corner). Whether the box is "min-inclusive max-inclusive" or "min-inclusive max-exclusive" depends on the derived BBox specialization (integer vs floating point).
