Detailed Description

Global read configuration passed to every codec during deserialization.

An instance of this struct is threaded through all codec readTopology() and readBuffers() calls so that site-wide policy (clipping, read mode) and any type-specific overrides are available in a single place.

Clipping
When clipBBox is non-empty (i.e. !clipBBox.empty()), codecs should restrict the voxel data they load to the region that intersects that world-space bounding box. An empty bbox (the default) means no clipping is applied.
Read mode
readMode controls the granularity and on-the-fly conversion applied during deserialization. The default, ReadMode::Original, loads both topology and value buffers without modification. ReadMode::Half, ReadMode::Bool, and ReadMode::Mask request in-place type conversion as data is read. ReadMode::TopologyOnly skips value buffers entirely, which can be significantly faster when only the active-voxel mask is needed. ReadMode::MetadataOnly skips both topology and value buffers, reading only grid metadata and transform.
Per-type options
typeData allows callers to attach codec-specific configuration for individual grid types. Entries are keyed by the grid type string (e.g. "Vec3SGrid") and hold a ReadTypedOptions-derived object. Codecs retrieve their entry via ReadTypedOptions::cast<T>().
