Detailed Description

template<typename T>
class nanovdb::math::Vec4< T >

A simple vector class with four components, similar to openvdb::math::Vec4.

Naturally aligned (alignof(T)). Vec4 is a grid value type, so its alignment sets field offsets in the NanoVDB file format and in PNanoVDB. Use Vec4Aligned for over-aligned user arrays.
